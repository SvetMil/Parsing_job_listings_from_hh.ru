# AutoPoster HH.ru 🤖💼

Автоматизированный скрипт для парсинга свежих вакансий с платформы **hh.ru** и их мгновенной кросс-публикации в каналы **Telegram** и сообщества **ВКонтакте**. Проект разработан в качестве HR-витрины для демонстрации возможностей автоматизации рутинных процессов.

## 🚀 Основные фичи
- **Умный парсинг:** Сбор только актуальных вакансий по заданным фильтрам.
- **Кросс-платформенность:** Одновременная отправка постов в Telegram и VK API.
- **Защита от дублей:** Локальная база данных (`seen_vacancies.txt`) предотвращает повторную отправку одних и тех же вакансий.
- **Полная автоматизация:** Скрипт работает автономно на серверах GitHub Actions и не требует локального компьютера.
- **Оптимизация сборки:** Реализовано кэширование `pip`-зависимостей, сокращающее время работы экшена до минимума.

## 🛠 Технологический стек
- **Language:** Python 3.11
- **Automation:** GitHub Actions (Синтаксис YAML, Кэширование, Cron-расписание)
- **APIs:** Telegram Bot API, VK API, HeadHunter API

## ⏱ Расписание работы (Cron)
Скрипт запускается автоматически по будням (с понедельника по пятницу) 3 раза в день в периоды наибольшей активности соискателей:
- **08:20** (Красноярск) / 01:20 (UTC)
- **12:00** (Красноярск) / 05:00 (UTC)
- **17:00** (Красноярск) / 10:00 (UTC)

## ⚙️ Настройка проекта

Для работы автопостинга в репозитории настроены следующие **GitHub Secrets**:
- `TELEGRAM_TOKEN` — токен вашего Telegram-бота.
- `TELEGRAM_CHAT_ID` — ID канала или чата для публикаций.
- `VK_TOKEN` — токен доступа VK API.
- `VK_USER_ID` — ID целевой страницы/сообщества VK.
